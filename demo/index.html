  How it works
  
Check, widen, share, validate

  

    
CheckEvery tool call is checked in code before it runs. The model is never asked.median 0.03 ms

    
WidenA block becomes the broadest rule that still allows normal work.0 false alarms on known-good

    
ShareThe rule travels through the Flower coordinator. Only the rule, never data.max 3 new rules per message

    
ValidateEach agent tests the rule on its own work before using it.poisoned rules rejected

  Works with
  
Your agents, your rules

  
Flower Agents built in. Hooks for Claude Code, Codex, Cursor, GitHub Copilot, Gemini CLI and Grok. Rule packs shaped like skills: secrets, git-safety, publishing, customer-data. python3 tools/warden.py init sets up a project; review shows what the fleet learned.

  
    
    
  • Rules can be phrased around. Wagent is a layer on top of sandboxes, not a replacement.
    • 
    
  • Shared rules are validated and rate-limited; signing is built on a branch.
    • 
    
  • "Ask" actions are held on Flower today; approval cards are next.
